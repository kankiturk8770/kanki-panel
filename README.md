# Kanki Panel

پنل سبک و کامل برای **WireGuard**، **AmneziaWG** و **Hysteria2** با **ربات فروش تلگرام داخلی**، نوشته‌شده با Rust.

## ویژگی‌ها
- پنل وب فارسی با تم طلایی: کاربران، نودها، پلن‌ها، تنظیمات، بکاپ
- حجم، تاریخ انقضا، اتصال همزمان، قطع خودکار، آمار مصرف و آنلاین
- چند سرور (نود) با یک پنل
- سازگار با اپ اندروید Kanki VPN (لینک `/sub/bub-…`)
- لینک خام Hysteria2 برای v2rayNG / Hiddify: `/sub/<code>/raw`
- ربات فروش: پلن‌ها، تست رایگان، کارت‌به‌کارت، زرین‌پال، NOWPayments، کیف پول ارزی، تمدید، کد تخفیف، دعوت دوستان با هدیه، عضویت اجباری کانال، هشدار اتمام حجم/زمان، بکاپ روزانه، پیام همگانی، مدیریت کامل کاربران
- API کامل با کلید (`Authorization: Bearer <api_key>`)

## نصب
روی سرور اوبونتو (۲۲.۰۴ یا ۲۴.۰۴) با کاربر root:
```bash
bash <(curl -fsSL https://raw.githubusercontent.com/<USER>/<REPO>/main/install.sh)
```
همه‌چیز (دامنه، SSL، ادمین، توکن ربات، آیدی ادمین، پورت‌ها) موقع نصب پرسیده می‌شود.

## نکته‌ها
- دامنه باید **مستقیم** (بدون پروکسی Cloudflare) به IP سرور اشاره کند.
- پورت 80 هنگام گرفتن SSL باید آزاد باشد.
- برای سرورهای اضافه، همان اسکریپت را با گزینه‌ی «نود» اجرا کنید.
