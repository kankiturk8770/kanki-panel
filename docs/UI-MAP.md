# نقشهٔ رابط کاربری: هر چیز کجا رفت (نسخهٔ 3.21.0)

قانون‌ها در `CLAUDE.md` (دستور طراحی) هستند. اجزای مشترک در اول `assets/web/panel.js`: `kuHead`، `kuTabs`،
`kuStats`، `kuGroup`، `kuSwitch`، `kuLine`، `kuItem`، `kuTag`، `kuMenu` (منوی «⋯»)، `coreTunRows` (تب تانل هر هسته)،
`corePage` / `CTABS` (صفحهٔ هر هسته). CSS آن‌ها بخش «the parts every page is built from» در `index.html`.

## هر هسته = یک خانه با تب‌های ثابت
| هسته | آدرس | تب‌ها |
|---|---|---|
| Xray | `#xray/<tab>` | وضعیت · سرورها · تانل · اینباندها · روتینگ · تنظیمات |
| KANKI MIX | `#kmix/<tab>` | وضعیت · سرورها · تانل · تنظیمات |
| microtun | `#mtun/<tab>` | وضعیت · سرورها · تانل · تنظیمات |
| WireGuard / AmneziaWG / Hysteria2 | `#wg/<tab>` … | وضعیت · سرورها · تانل · تنظیمات |
| DNS کانکی | `#dns/<tab>` | وضعیت · سرورها · پابجی و بازی‌ها · سرویس‌ها · کاربران · لاگ · تنظیمات و SSL |

آدرس‌های قدیمی: `#xray` و `#xray/overview` ← `#xray/status` و `#xray/servers`؛ `#xray/clients` ← `#xray/status`؛
`#kmix` و بقیه بدون تب ← تب وضعیت.

## Xray
| قبلاً | حالا |
|---|---|
| خاموش/روشن برای همه (سرصفحه) | وضعیت ← گروه Xray ← «همه‌ی کاربران» |
| روشن بودن Xray (تنظیمات) | وضعیت ← سوییچ «Xray روشن است» |
| کلاینت‌های آنلاین (تب جدا) | وضعیت ← گروه «آنلاین الان» |
| افزودن سرور (سرصفحه) | سرورها ← «افزودن Xray به یک سرور» (تنها جا) |
| + اینباند (۴ جا) | اینباندها ← «اینباند جدید» (تنها جا) |
| کانفیگ دوم (پنجرهٔ سرور) | تانل ← ردیف هر سرور |
| ویرایش سرور، کانفیگ، تعمیر، سلامت | سرورها ← ردیف سرور (جزئیات Xray روی همان سرور) |
| حذف Xray از سرور | همان‌جا، جدا و پایین، با تأیید |
| ویرایش، کپی، JSON، صفر کردن، حذف اینباند | منوی «⋯» ردیف اینباند (حذف آخر و جدا) |
| لینک‌ها | دکمهٔ اصلی ردیف اینباند |
| روشن/خاموش اینباند | سوییچ با برچسب «روشن» |
| آدرس `0.0.0.0:port` | آدرس عمومی: `link_host` یا آدرس سرور + پورت |
| اسم «دروازه» | همه‌جا «اینباند» |

## KANKI MIX
| قبلاً | حالا |
|---|---|
| روشن بودن، برای همه | وضعیت |
| روشن روی این سرور، پورت، مسیر اصلی، آدرس، ری‌استارت | سرورها ← ردیف سرور |
| کانفیگ دوم (آدرس ایران، پورت، اسم در اپ) | تانل ← ردیف سرور (`kmTunRows`، `kmSaveTun`) |
| پورت پیش‌فرض، FEC، گیمینگ، پورت‌های اضافه | تنظیمات |
| «به‌زودی» | حذف شد (کاری نمی‌کرد) |

## microtun
| قبلاً | حالا |
|---|---|
| روشن بودن، برای همه | وضعیت |
| پورت و آدرس هر سرور (ذخیرهٔ فوری) | سرورها ← ردیف سرور با دکمهٔ ذخیره (`kcSaveOne`) |
| کانفیگ دوم | تانل (`coreTunRows('mtun')`) |
| پورت، تکرار بسته، MTU، لینک تست | تنظیمات |

## WireGuard / AmneziaWG / Hysteria2
| قبلاً | حالا |
|---|---|
| آمار، برای همه | وضعیت |
| ردیف سرور (پورت، مبهم‌سازی، ری‌استارت…) | سرورها |
| کانفیگ دوم (`tunCopy`) | تانل |
| دامنه‌های مستقیم AWG (جدول) | تنظیمات AWG (ردیف آیتم) |

## DNS کانکی
| قبلاً | حالا |
|---|---|
| + رله و + سرور DNS (سرصفحه) | سرورها ← «افزودن سرور DNS» (یک دکمه، انتخاب خروجی یا رله) |

## سرورها
| قبلاً | حالا |
|---|---|
| افزودن سرور (سرصفحه) | فقط در گروه خارج / ایران |
| کارت دوستونه و کشو | ردیف آیتم با جزئیات باز شونده، مثل بقیه |
| — | «هسته‌های این سرور»: خلاصهٔ فقط‌خواندنی، هر کدام به تب سرورهای همان هسته |
| حذف سرور | جدا و پایین |

## نوار هسته‌ها
کارت‌های بزرگ (`dressRail`) و ریل تراشه‌ها (`chips`) و کشوی کناری (`drawerDress`) حذف شدند. نوار هسته‌ها
دکمه‌های ساده است و روی موبایل به خط بعد می‌رود (هیچ دکمه‌ای نصفه نیست).

## مانده
کاربران، تانل‌ها، پورت‌ها، داشبورد، ربات و سیستم هنوز ظاهر قدیمی دارند (کار بعدی، با همین اجزا).
