# راهنمای DNS کانکی و Xray (نسخه ۳.۴)

## DNS کانکی

### چطور کار می‌کند
- مشتری DNS را روی گوشی یا کنسول می‌گذارد.
- دامنه‌ی سرویس‌های تحریمی (بازی، دانلود، هوش مصنوعی…) به سرور شما جواب داده می‌شود و سرور اتصال را بدون باز کردن رمز رد می‌کند.
- بقیه‌ی سایت‌ها مستقیم می‌روند. محدودیت سرعت ندارد.
- **فقط مشتری‌ها:** هر کاربر یک توکن DNS دارد. وقتی از آدرس شخصی‌اش (DoT یا DoH) استفاده کند، IP او برای چند ساعت باز می‌شود. هر کس دیگری فقط REFUSED می‌گیرد.

### راه‌اندازی
1. **سرور DNS خروجی (خارج):** نودها › افزودن نود › «نود DNS خروجی» (یا از صفحه‌ی DNS کانکی).
   - اسم و برچسب بده (مثلاً `de`).
   - دستور نصب را روی سرور بزن.
   - پورت‌های 53، 80، 443 و 853 روی این سرور باید آزاد باشند، پس برای DNS سرور جدا بگذار.
2. **ریلی ایران (اختیاری):** «نود ریلی DNS» را بزن، خروجی‌اش را انتخاب کن و ترنسپورت را بگذار (پیش‌فرض tcpmux).
   - پنل خودش تانل مخفی بین ریلی و خروجی را می‌سازد.
3. **صفحه‌ی DNS کانکی:**
   - «DNS روشن است» را بزن.
   - دامنه را بگذار، مثلاً `dns.kanki.pro`. هر سرور اسمی مثل `de.dns.kanki.pro` می‌گیرد.
4. **گواهی و رکوردها:**
   - سرویس دامنه (Cloudflare یا ArvanCloud) را انتخاب کن و توکن API را بده.
   - «الان رکوردها را بساز و گواهی بگیر» را بزن.
   - پنل رکورد A هر سرور (و `*.` آن) را می‌سازد و گواهی Let's Encrypt می‌گیرد. هر ۶۰ روز هم خودش تمدید می‌کند.
   - برای سرور ایران هم کار می‌کند، چون چیزی لازم نیست از بیرون به آن برسد.
5. **سرویس‌ها:** گروه‌ها را روشن یا خاموش کن. دامنه‌ی اضافه هم می‌توانی بنویسی.
6. **کاربر:** در فرم کاربر تیک **DNS** را بزن.

### آدرس‌های مشتری
در صفحه‌ی ساب و در JSON اپ (`dns`) هست:
- **DoT (Private DNS اندروید):** `<توکن>.de.dns.kanki.pro`
- **DoH:** `https://de.dns.kanki.pro/dns-query/<توکن>`
- **ثبت IP** (اپ موقع عوض شدن شبکه صدا می‌زند): `https://de.dns.kanki.pro/r/<توکن>`

## Xray

### راه‌اندازی
1. صفحه‌ی Xray › «افزودن سرور».
   - سرور پنل یا یک سرور جدید (دستور نصب) را انتخاب کن.
   - ایجنت خودش Xray-core را نصب می‌کند. اگر گیت‌هاب بسته باشد، از طریق پنل نصب می‌کند.
2. «+ اینباند»:
   - پروتکل: VLESS، VMess، Trojan یا Shadowsocks
   - ترنسپورت: TCP، WS، gRPC، HTTPUpgrade، XHTTP یا mKCP
   - امنیت: TLS یا REALITY. کلیدهای REALITY را پنل می‌سازد.
   - برای CDN: در بخش «لینک اشتراک» آدرس CDN، پورت 443 و «TLS در CDN» را بزن.
3. در فرم کاربر تیک **Xray** را بزن.
   - کاربر کلاینت همه‌ی اینباندها می‌شود. در هر اینباند می‌شود فقط چند کاربر را انتخاب کرد.
   - ترافیک Xray به مصرف کاربر اضافه می‌شود.
4. لینک‌ها در صفحه‌ی ساب (کپی و QR)، در لینک خام (v2rayNG / Hiddify) و در JSON اپ (`xray`) هستند.

### نکته‌ها
- هر کانفیگ قبل از اجرا با `xray run -test` چک می‌شود. اگر Xray قبولش نکند، کانفیگ قبلی می‌ماند و خطا در کارت سرور نشان داده می‌شود.
- WireGuard، AmneziaWG، Hysteria2 و تانل‌ها دست نخورده‌اند.
