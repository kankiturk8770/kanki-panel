# راهنمای DNS کانکی و Xray (نسخه ۳.۵)

## DNS کانکی

### چطور کار می‌کند
- مشتری DNS را روی گوشی یا کنسول می‌گذارد.
- دامنه‌ی سرویس‌های تحریمی (بازی، دانلود، هوش مصنوعی…) به سرور شما جواب داده می‌شود و سرور اتصال را بدون باز کردن رمز رد می‌کند.
- بقیه‌ی سایت‌ها مستقیم می‌روند. محدودیت سرعت ندارد.
- **فقط مشتری‌ها:** هر کاربر یک توکن DNS دارد. وقتی از آدرس شخصی‌اش (DoT یا DoH) استفاده کند، IP او برای چند ساعت باز می‌شود. هر کس دیگری فقط REFUSED می‌گیرد.

### راه‌اندازی
1. **سرور DNS خروجی (خارج):** نودها › افزودن نود › «نود DNS خروجی» (یا از صفحه‌ی DNS کانکی).
   - اسم و برچسب بده (مثلاً `de`).
   - دستور نصب را روی سرور بزن.
   - پورت‌های 53، 80، 443 و 853 روی این سرور باید آزاد باشند، پس برای DNS سرور جدا بگذار.
2. **ریلی ایران (اختیاری):** «نود ریلی DNS» را بزن، خروجی‌اش را انتخاب کن و ترنسپورت را بگذار (پیش‌فرض tcpmux).
   - پنل خودش تانل مخفی بین ریلی و خروجی را می‌سازد.
3. **صفحه‌ی DNS کانکی:**
   - «DNS روشن است» را بزن.
   - دامنه را بگذار، مثلاً `dns.kanki.pro`. هر سرور اسمی مثل `de.dns.kanki.pro` می‌گیرد.
4. **SSL:**
   - رکورد A اسم هر سرور را در سرویس دامنه‌ات خودت به IP همان سرور بزن.
   - certbot روی خود سرور گواهی را می‌گیرد (بدون ایمیل) و خودش تمدید می‌کند. پورت ۸۰ سرور باید از بیرون باز باشد.
   - DNS داخل برنامه (رفع تحریم) بدون گواهی هم کار می‌کند؛ گواهی فقط برای Private DNS و DoH لازم است.
5. **سرویس‌ها:** گروه‌ها را روشن یا خاموش کن. دامنه‌ی اضافه هم می‌توانی بنویسی.
6. **کاربر:** در فرم کاربر تیک **DNS** را بزن.

### آدرس‌های مشتری
در صفحه‌ی ساب و در JSON اپ (`dns`) هست:
- **DoT (Private DNS اندروید):** `<توکن>.de.dns.kanki.pro`
- **DoH:** `https://de.dns.kanki.pro/dns-query/<توکن>`
- **ثبت IP** (اپ موقع عوض شدن شبکه صدا می‌زند): `https://de.dns.kanki.pro/r/<توکن>`

## Xray

### راه‌اندازی
1. صفحه‌ی Xray › «افزودن سرور».
   - سرور پنل یا یک سرور جدید (دستور نصب) را انتخاب کن.
   - ایجنت خودش Xray-core را نصب می‌کند. اگر گیت‌هاب بسته باشد، از طریق پنل نصب می‌کند.
2. «+ اینباند»:
   - پروتکل: VLESS، VMess، Trojan یا Shadowsocks
   - ترنسپورت: TCP، WS، gRPC، HTTPUpgrade، XHTTP یا mKCP
   - امنیت: TLS یا REALITY. کلیدهای REALITY را پنل می‌سازد.
   - برای CDN: در بخش «لینک اشتراک» آدرس CDN، پورت 443 و «TLS در CDN» را بزن.
3. در فرم کاربر تیک **Xray** را بزن.
   - کاربر کلاینت همه‌ی اینباندها می‌شود. در هر اینباند می‌شود فقط چند کاربر را انتخاب کرد.
   - ترافیک Xray به مصرف کاربر اضافه می‌شود.
4. لینک‌ها در صفحه‌ی ساب (کپی و QR)، در لینک خام (v2rayNG / Hiddify) و در JSON اپ (`xray`) هستند.

### نکته‌ها
- هر کانفیگ قبل از اجرا با `xray run -test` چک می‌شود. اگر Xray قبولش نکند، کانفیگ قبلی می‌ماند و خطا در کارت سرور نشان داده می‌شود.
- WireGuard، AmneziaWG، Hysteria2 و تانل‌ها دست نخورده‌اند.

## تازه‌های نسخه ۳.۵

### منو
- منو گروه‌های بازشو دارد. «سرویس‌های VPN» باز می‌شود: همه‌ی سرویس‌ها، کانکی VPN، Xray.
- روی گوشی منوی همبرگری نیست. زیر نوار بالا یک ردیف بخش هست. با زدن «سرویس‌های VPN» کاشی‌ها باز می‌شوند: کانکی VPN و Xray کنار هم.
- صفحه‌ی «همه‌ی سرویس‌های VPN»: کانکی VPN و Xray کنار هم، DNS کانکی زیرشان.

### Xray
- تب‌ها: نمای کلی، اینباندها، کلاینت‌های آنلاین، روتینگ و خروجی‌ها، تنظیمات.
- هر اینباند: حجم کل و تاریخ توقف (خودش می‌ایستد)، صفر کردن ترافیک، کپی روی پورت آزاد بعدی، لینک و QR هر کاربر، JSON.
- ساخت سریع: VLESS + REALITY، XHTTP + REALITY، WS برای CDN، gRPC + REALITY، Trojan + TLS، Shadowsocks 2022.
- گزینه‌های بیشتر: آدرس listen، تنظیم Sniffing، PROXY protocol، نسخه‌ی TLS، رد SNI ناشناس، گواهی از فایل روی سرور، xver و اختلاف ساعت REALITY، ضربان WS، پدینگ XHTTP، تنظیم mKCP، فال‌بک.
- **خروجی‌ها:** سرور دیگر از روی لینکش (مثلاً سرور ایران ← سرور خارج)، SOCKS، HTTP یا JSON. دکمه‌ی «بررسی» نشان می‌دهد Xray چه می‌گیرد.
- **قانون‌ها:** با دامنه، IP، پورت، شبکه، پروتکل، اینباند یا کاربر. از بالا به پایین چک می‌شوند. هر قانون جدا روشن و خاموش می‌شود.
- **SSL:** موقع «افزودن سرور» دامنه‌ی سرور را بنویس و «گرفتن خودکار SSL» روشن بماند.
  - certbot روی خود سرور گواهی را می‌گیرد (`certbot --standalone`، بدون ایمیل) و خودش تمدید می‌کند.
  - دامنه باید به همان سرور وصل باشد و پورت ۸۰ سرور باز باشد.
  - هر اینباند TLS با گواهی «خودکار» و SNI خالی، همین گواهی را برمی‌دارد.
  - اگر نشد، خطا روی کارت سرور نشان داده می‌شود و ۱۰ دقیقه بعد دوباره امتحان می‌شود.
- قانون‌های آماده: مسدود کردن IP داخلی، تورنت، تبلیغات و سایت‌های ایرانی.
- بعد از تغییر روتینگ «ذخیره‌ی روتینگ» را بزن.

### DNS کانکی
- کاربر در برنامه‌ی کانکی «رفع تحریم» را می‌زند و به DNS وصل می‌شود؛ بازی و سایت‌های تحریمی از سرور رد می‌شوند (SNI پروکسی).
- SSL هر سرور DNS را certbot روی خود سرور برای اسم همان سرور می‌گیرد. تنظیم API لازم نیست.
- تب‌ها: نمای کلی، سرورها، سرویس‌ها، کاربران DNS، تنظیمات و SSL.
- هر سرور: تعداد درخواست، مسیردهی‌شده، درصد کش، ردشده و IPهای مجاز.
- «بررسی یک دامنه»: نشان می‌دهد سایت از DNS رد می‌شود یا نه و در کدام سرویس است.
- سرویس‌ها: بخش‌های جمع‌شونده با جستجو و «همه روشن / همه خاموش».
- کاربران DNS: IPهای ثبت‌شده‌ی هر کاربر، کپی آدرس Private DNS و «پاک کردن IPها».
