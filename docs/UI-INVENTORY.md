# فهرست رابط کاربری پیش از بازطراحی (نسخهٔ 3.20.1)

هر تنظیم و هر دکمهٔ هر هسته، پیش از بازطراحی کجا بود. علامت‌ها: **⧉** تکراری (دو جا یا بیشتر)، **↯** پخش‌شده یا
جای اشتباه، **⚠** مشکل ظاهری.

## Xray (`p_xray`)
| چیز | کجا بود | علامت |
|---|---|---|
| خاموش/روشن برای همهٔ کاربران | سرصفحه | |
| افزودن سرور | سرصفحه (`xrAddNode`) | ↯ در صفحهٔ یک هسته جای «افزودن سرور» نیست |
| + دروازه (اینباند) | سرصفحه، تب «دروازه‌ها»، داخل پنجرهٔ هر سرور، صفحهٔ «نمای کلی» (`vhXray`) | ⧉ چهار جا |
| اسم «اینباند» / «دروازه» | توضیح صفحه «اینباند»، تب و دکمه «دروازه» | ⧉ دو اسم برای یک چیز |
| روشن بودن Xray | تب «تنظیمات» | ↯ وضعیت کل هسته جایش تب وضعیت است |
| سرورهای Xray | تب «سرورها» در سه کادر تو در تو + دکمهٔ «سرورها» به صفحهٔ دیگر؛ روی موبایل تراشهٔ پرچم با «VPN T» | ⚠ کارت در کارت، اسم سرور دیده نمی‌شود |
| کانفیگ دوم (دامنهٔ ایران) | داخل پنجرهٔ هر سرور Xray | ↯ |
| کارت اینباند | آدرس `0.0.0.0:port`، سوییچ بی‌برچسب، شش دکمه پشت سر هم، «حذف» کنار «کپی» | ⚠ |
| کلاینت‌های آنلاین | تب جدا | |
| روتینگ، خروجی‌ها | تب «روتینگ» | |
| نسخه، لاگ، IPv4 | تب «تنظیمات» | |

## KANKI MIX (`p_kmix`)
| چیز | کجا بود | علامت |
|---|---|---|
| همه‌چیز (آمار، سرورها، تنظیمات، توضیح) | یک صفحهٔ بلند بدون تب | ⚠ |
| سرورها | کارت با دکمهٔ «سرورها» به صفحهٔ دیگر؛ روی موبایل ریل تراشه (`chips()`)، روی دسکتاپ کارت با کشوی کناری (`drawerDress`) | ⚠ سه شکل برای یک لیست |
| روشن/خاموش، پورت، مسیر هر سرور | پنجرهٔ هر سرور | |
| کانفیگ دوم (`tun_host`، پورت، اسم) | همان پنجرهٔ هر سرور، زیر تنظیمات سرور | ↯ قاطی با تنظیمات سرور |
| روشن بودن KANKI MIX، پورت، FEC، گیمینگ، پورت‌های اضافه | کارت «تنظیمات» کنار سرورها | |
| «چطور کار می‌کند» و «به‌زودی» | پایین صفحه، همیشه باز | |

## microtun (`kcPage`)
| چیز | کجا بود | علامت |
|---|---|---|
| همه‌چیز | یک صفحهٔ بلند بدون تب | ⚠ |
| پورت و آدرس هر سرور | فیلدهای کوچک داخل ردیف سرور، هر تغییر فوراً ذخیره | ⚠ |
| کانفیگ دوم | `details` داخل ردیف هر سرور | ↯ |
| لینک تست | کارت جدا | |

## WireGuard / AmneziaWG / Hysteria2 (`protoPage`)
| چیز | کجا بود | علامت |
|---|---|---|
| همه‌چیز | یک صفحه بدون تب | ⚠ |
| سرورها | ریل تراشه روی موبایل | ⚠ |
| کانفیگ دوم | داخل پنجرهٔ هر سرور (`tunCopy`) | ↯ |
| دامنه‌های مستقیم (AWG) | جدول زیر لیست سرورها (اسکرول افقی روی موبایل) | ⚠ |

## DNS کانکی (`p_dns`)
| چیز | کجا بود | علامت |
|---|---|---|
| + رله، + سرور DNS | سرصفحه؛ و تب سرورها لینک «در صفحهٔ سرورها اضافه کن» | ⧉ و متناقض |
| دکمهٔ DNS در نوار پایین | DNS جزو «هسته‌ها» بود، دکمهٔ DNS روشن نمی‌شد | ↯ (در 3.20.1 درست شد) |

## سرورها (`pNodes`)
| چیز | کجا بود | علامت |
|---|---|---|
| افزودن سرور | سرصفحه + هر گروه (خارج / ایران) | ⧉ |
| ظاهر | دو ستون کارت با مداد و کشوی کناری | ⚠ با بقیهٔ لیست‌ها فرق داشت |
| هسته‌های سرور | فقط متن «پورت‌ها در سرویس‌های VPN است» | ↯ |
| حذف سرور | ردیف دکمه‌ها کنار بقیه | ⚠ |

## نوار هسته‌ها (`sectabs` با `dressRail`)
کارت‌های بزرگ ۱۳۶ پیکسلی که از دو طرف بریده می‌شدند («ضد DPI» نصفه). ⚠

## نمای کلی (`p_vpn`)
دکمهٔ «+ اینباند جدید» (چهارمین جای افزودن اینباند). ⧉
