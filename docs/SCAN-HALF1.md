- **H2** ✔ `src/panel/api.rs:1049-1057` (`settings_put`) — توکن API با دسترسی فقط `settings` می‌تواند `/etc/kanki/repo` (منبع آپدیت) را عوض
  کند. آپدیت شبانه / «آپدیت همه» / «آپدیت» فایل را از آن ریپو می‌گیرد و sha256 را هم از همان ریپو (`admin.rs:747,791`، بدون امضا)، و با root
  نصب می‌شود. `update_apply` خودش ورود می‌خواهد (`admin.rs:813`) ولی عوض کردن منبع نه. انتقال پنل هم `install.sh` را از همین ریپو می‌گیرد.
- **H3** ✔ `src/bot/bot.rs:1231` — ربات به هر دکمه اول یک جواب خالی می‌دهد (`self.answer(&qid, "", false)`)؛ تلگرام فقط یک جواب قبول می‌کند،
  پس همهٔ هشدارهای بعدی همان دکمه دیده نمی‌شوند: «هنوز پرداختی تأیید نشده است» (1393)، «قبلاً فعال» (1387)، «قبلاً بررسی شده» ادمین (1712)،
