# Game-FEC، HQ-QUIC و FakeTCP: سه پروتکل VPN جدا برای اپ کانکی — نسخهٔ ۳.۱۴

سه ترنسپورت بخش تانل‌ها حالا **هستهٔ VPN برای کاربر** هم هستند، کنار KANKI MIX، Hysteria2 و بقیه:

| هسته | پایه | روی سیم | مناسب برای |
|---|---|---|---|
| **Game-FEC** (`game`) | KCP سریع + FEC رید-سولومون + ماسک | UDP بدون امضا | بازی (پابجی و …)، پینگ کم |
| **HQ-QUIC** (`hq`) | QUIC زیر ماسک + BBR | UDP بدون امضا | اینترنت پرلاس، سرعت دانلود |
| **FakeTCP** (`faketcp`) | KCP داخل TCP ساختگی | یک نشست TCP | جایی که UDP بسته یا محدود است |

خود کد تانل‌ها (ماسک، FEC، QUIC ماسک‌شده، FakeTCP، لایهٔ رکورد و mux) **دست نخورده** و همان فایل‌ها استفاده
شده‌اند؛ فقط یک لایه رویشان اضافه شده (پوشهٔ `src/tunnel/kcore/`). دو تغییر کوچک در کد قبلی، که رفتار تانل‌ها را
عوض نمی‌کنند:
- `mux.rs`: پرچم `public_only` (پیش‌فرض خاموش؛ تانل‌ها خاموش نگهش می‌دارند). هسته‌ها روشنش می‌کنند تا کاربر
  نتواند به آدرس‌های داخلی سرور (127.0.0.1، شبکهٔ خصوصی و …) برسد.
- `faketcp.rs`: `as u32` → `as libc::socklen_t` تا روی گوشی‌های ۳۲ بیتی هم کامپایل شود (روی سرور همان u32 است).

## چطور کار می‌کند

```text
 بازی/اپ‌ها ─ کارت VPN ─ hev-socks5-tunnel ─ SOCKS5 ─ libkcore.so ══ game / hq / faketcp ══ سرور ─ اینترنت
                                                       TCP → جریان mux (KCP+FEC / QUIC / FakeTCP)
                                                       UDP → دیتاگرام جدا (game، hq) یا mux (faketcp)
```

1. **ورود کاربر:** بعد از دست‌دادن رمزنگاری تانل (X25519 + ChaCha20-Poly1305، با کلید `door` مشترک سرورها)،
   اپ با HMAC کلید خودش ثابت می‌کند کیست. **خود کلید هیچ‌وقت فرستاده نمی‌شود**؛ زمان و nonce دارد پس تکرار
   (replay) نمی‌شود. هر کاربر کلید خودش را دارد (از کد اشتراک ساخته می‌شود): لینک تازه = کلید تازه،
   کاربر منقضی/غیرفعال/حذف‌شده همان لحظه قطع می‌شود. مصرف و تعداد دستگاه مثل بقیهٔ پروتکل‌ها شمرده می‌شود.
2. **پراکسی کامل:** اپ هر `ip:port` عمومی را می‌خواهد (TCP و UDP). آدرس‌های داخلی و خود سرور رد می‌شوند.
3. **مسیر سریع بازی (بهینه برای پابجی):**
   - بستهٔ UDP بازی **داخل جریان مطمئن نمی‌رود** (آنجا یک بستهٔ گم‌شده همهٔ بسته‌های بعدی را منتظر نگه می‌داشت).
     هر بستهٔ بازی یک دیتاگرام جداست، با کلید جدای همان نشست مهر می‌شود.
   - بسته‌های کوچک (تا ۴۰۰ بایت؛ بسته‌های پابجی ۴۰ تا ۳۰۰ بایت‌اند) **۲ یا ۳ بار** فرستاده می‌شوند، هر نسخه
     با نمک و پدینگ خودش (شبیه هم نیستند). گیرنده اولین نسخه را برمی‌دارد و بقیه را با پنجرهٔ ضدتکرار دور
     می‌ریزد، پس بازی هیچ بستهٔ دوتایی نمی‌بیند. بسته‌های بزرگ (ویدیو، دانلود) یک بار می‌روند تا حجم هدر نرود.
   - بستهٔ بزرگ‌تر از یک دیتاگرام تکه‌تکه می‌رود و آن طرف سرهم می‌شود.
   - هر جریان UDP یک مسیر ثابت دارد (سرور بازی همیشه یک پورت مبدأ می‌بیند).
   - سوکت‌های بازی DSCP EF (اولویت بلادرنگ) دارند؛ مودم/وای‌فای‌هایی که رعایتش می‌کنند بستهٔ بازی را جلو می‌اندازند.
   - گوشی که از وای‌فای به دیتا می‌رود: جواب‌ها به آدرس تازه می‌روند، اتصال خودش دوباره برقرار می‌شود.
   - سایت‌ها، لابی و دانلود آپدیت بازی روی جریان KCP + FEC (یا QUIC) می‌روند.

**نتیجهٔ تست واقعی** (فایل `src/tunnel/kcore/tests.rs`، ۴۰۰ بستهٔ ۸۰ تا ۲۰۰ بایتی، ۱۵٪ لاس در هر جهت):

## در پنل

هر کدام یک **پروتکل جدا** است، مثل KANKI MIX، با بخش خودش در «سرویس‌ها»:
**Game-FEC** (`#kgame`)، **HQ-QUIC** (`#khq`)، **FakeTCP** (`#kftcp`).
- هر بخش: روشن/خاموش، پورت پیش‌فرض (Game-FEC `4100/UDP`، HQ-QUIC `4101/UDP`، FakeTCP `4102/TCP`)، و برای هر سرور
  پورت جدا، آدرس جدا و خاموش/روشن جدا. Game-FEC تعداد نسخهٔ هر بستهٔ بازی (۱، ۲، ۳) و FEC جریان را هم دارد؛ HQ-QUIC
  نام TLS را.
- **روشن برای همه‌ی کاربران / خاموش برای همه** بالای هر بخش.
- در فرم کاربر (ساخت/ویرایش) هر سه کنار WireGuard، AmneziaWG، Hysteria2 و KANKI MIX **تیک جدا** دارند. کاربری که
  فقط Game-FEC دارد روی HQ-QUIC و FakeTCP رد می‌شود.
- این‌ها از تانل‌ها جدا هستند: روی هر سرور VPN با پورت خودشان اجرا می‌شوند و به تانل‌ها کاری ندارند (فقط کد
  ترنسپورت مشترک است). فایروال خود سرور را پنل باز می‌کند؛ فایروال دیتاسنتر را خودت باز کن.
- سرورها چیزی نصب نمی‌کنند: agent را به ۳.۱۴ آپدیت کن.

## برای اپ اندروید (کانکی)

### فایل
از Releases با تگ `kanki-core` (یا artifact اکشن): `libkcore-arm64-v8a.so` و `libkcore-armeabi-v7a.so` را با نام
`libkcore.so` در `app/src/main/jniLibs/<abi>/` بگذار (مثل `libhysteria.so`، این در واقع برنامه است)،
و در `build.gradle.kts`: `keepDebugSymbols += "**/libkcore.so"`.

### لینک‌ها در اشتراک
هر سرور در دادهٔ اشتراک (همان JSON داخل صفحه که اپ می‌خواند) یک فیلد تازه دارد:

```json
"kcore": [
  {"proto": "kgame", "kind": "game",    "title": "Game-FEC", "url": "kcore://ali:…@de.example.com:4100?type=game&door=…&fec=8:3&copies=2#…"},
  {"proto": "khq",   "kind": "hq",      "title": "HQ-QUIC",  "url": "kcore://ali:…@de.example.com:4101?type=hq&door=…&copies=2#…"},
  {"proto": "kftcp", "kind": "faketcp", "title": "FakeTCP",  "url": "kcore://ali:…@de.example.com:4102?type=faketcp&door=…#…"}
]
```

### اجرا (مثل Xray: SOCKS5 + hev-socks5-tunnel)

```kotlin
val bin = File(applicationInfo.nativeLibraryDir, "libkcore.so")
val p = ProcessBuilder(bin.path, "client", "--url", url, "--socks", "127.0.0.1:$socksPort", "--status")
    .redirectErrorStream(true).start()
// هر ۲ ثانیه یک خط JSON روی خروجی:
// {"up":true,"kind":"game","rtt":38,"fast":true,"rx":123456,"tx":7890,"error":""}
// بعد همان writeHev(mtu, …, socksPort) و TProxyStartService که برای Xray است (udp: 'udp').
```

- **پینگ لیست سرورها:** `libkcore.so ping --url <url>` → عدد میلی‌ثانیه (پینگ واقعی داخل خود هسته، با کلید
  همان کاربر)، یا `error: …` با کد خروج ۱.
- برنامهٔ خود اپ باید مثل Hysteria/Xray از VPN بیرون باشد (`addDisallowedApplication(packageName)`).
- **FakeTCP روی گوشی بدون روت کار نمی‌کند** (بستهٔ خام TCP لازم دارد). پیشنهاد: در اپ فقط Game-FEC و HQ-QUIC را
  نشان بده (FakeTCP را فقط برای گوشی روت‌شده یا لینوکس/روتر).
- حالت گیمینگ اپ: Game-FEC را انتخاب کن؛ `copies` از پنل می‌آید ولی اپ می‌تواند در لینک عوضش کند (`copies=3`).

## اجرای جدا روی لینوکس (بدون پنل)

```bash
kanki-core server -c /etc/kanki/kcore.json --stats /run/kcore-stats.json
# {"door":"…","game":4100,"hq":4101,"faketcp":4102,"fec":"8:3","copies":2,
#  "users":[{"name":"ali","key":"…","max":2}]}     ← با تغییر فایل خودش بارگذاری می‌شود
kanki-core url --kind game --server 1.2.3.4:4100 --door … --user ali --key …
kanki-core client --url 'kcore://…' --socks 127.0.0.1:10808 --status
kanki-core ping --url 'kcore://…'
```

## نظر من (چیزهایی که بعداً ارزش اضافه کردن دارند)
- **تعویض خودکار هسته در اپ:** اول Game-FEC؛ اگر UDP بسته بود HQ-QUIC، و برای گوشی روت FakeTCP.
- **پورت‌هاپینگ** برای Game-FEC (مثل بازهٔ پورت KANKI MIX) تا بستن یک پورت کافی نباشد.
